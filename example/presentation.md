## What is Marp?

Marp is a Markdown presentation ecosystem. It provides an intuitive experience for creating beautiful slide decks.

- **Markdown-driven**: Write your presentation in Markdown.
- **Themeable**: Use themes like `gödel` or any other MarpX theme.
- **Exportable**: Easily convert to HTML, PDF, or PowerPoint.
